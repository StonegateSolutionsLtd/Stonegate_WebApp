STONEGATE DESIGN SYSTEM

Brand personality:
- Professional
- Strong
- Local
- Reliable
- Modern
- Practical
- Premium without feeling expensive
- Real service business, not a tech startup

Visual goals:
- Real photographs are the main visual element
- Large truck/crew/job imagery
- Strong typography
- High contrast
- Generous spacing
- Clean layouts
- Avoid generic AI landing-page appearance

Do NOT use:
- purple gradients
- excessive gradients
- glassmorphism
- neon styling
- SaaS dashboard aesthetics
- excessive rounded cards
- identical 3-column card layouts everywhere
- huge walls of SEO copy
- stock moving-company photography
- unnecessary animations

Layout principles:
- Alternate image/text layouts
- Large photographic sections
- Before/after layouts for junk removal
- Real-job project cards
- Strong full-width CTA sections
- Clear visual separation between sections
- Allow some asymmetry
- Pages should not all use identical section order

Photography:
- Prefer real Stonegate photographs everywhere
- Truck
- Crew
- Actual moves
- Junk removal
- Before/after
- Equipment
- Customer jobs

If an appropriate real photo is unavailable:
ASK THE USER FOR IT.

Do not replace important real photography with stock photos.

Typography:
- Bold, modern headings
- Highly readable body copy
- Strong hierarchy
- Avoid generic/default-feeling typography where possible

Conversions:
Primary CTA:
Get a Free Quote

Secondary CTA:
Call Stonegate / View Pricing

Mobile:
- Excellent mobile layout is mandatory
- Important CTAs must remain accessible
- Images should crop intelligently
- No horizontal overflow
